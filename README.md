# Project NebulaBeat

Project NebulaBeat is a fast-paced rhythm-action game where players defend a spinning energy core by dragging to slice incoming explosive notes before they collide with it. Notes accelerate as they approach the core, while long notes require multiple separate drag strokes to clear.

Built with the [Godot Engine](https://godotengine.org/) (4.x).
